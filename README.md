# Refactoring Tool

Інструмент для рефакторингу С++ коду

## Функціональність

### Заплановано:
- [1] Rename Variable - перейменування змінних
- [8] Rename Method - перейменування методу
- [9] Add Parameter - додавання параметра
- [10] Remove Parameter - видалення параметра

Проєкт розроблено командою з чотирьох учасників.
